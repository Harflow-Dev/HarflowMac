## Native behavior

The Statistics header keeps the period selector visible during the
read and across unavailable states. The chart and coverage use the
selected bounded retained history. An older read cannot replace the
selected period's visible results.

The Reported cost card uses the same fresh admitting ctl probe as the
page request. It requires `statistics-cost-model.v1`, a complete
single-generation walk and matching coverage on every page. The Mac
reconciles counts against the entire snapshot before applying the
selected execution cohort. Native logical children are excluded.
Incomplete reported cost shows Unavailable and verified counts.
Unqualified cost shows coverage unavailable while complete time and
usage remain usable. A reported zero displays $0.00.

The approved partial-accounting drawing phrases coverage in harnesses.
The public `cost_coverage` counts executions. The Mac card uses
`Reported by X of Y executions` so each count reflects the contract,
including harnesses with a mix of reported and unavailable executions.

Resource Slots Retry reuses the existing read-only refresh. A failed
refresh keeps the last successful observation, disclosure, viewport
and exact permission reason. An unavailable read and a stale retained
observation each offer Retry in context.

The over-capacity meter uses consuming inventory holders and the queue
for the exact named resource. It distinguishes filled used cells,
an outlined overflow cell and dashed waiting cells. Borrowed holders
consume no cell. Larger or conflicting observations keep the exact
text summary. The native disclosure retains its full accessible label
and the keyboard focus ring clears the meter.
