# M08-A0 — workflow catalog background preparation

Status: locally implemented and verified, 2026-11-17. Base: `05d06c8`.

This bounded prerequisite extracts the immutable, Sendable definition catalog parser
from Start screen ownership into Workflow. It preserves catalog readiness and blocked
reasons, requires the workflows array and unique nonblank exact names, and retains
input order and complete record payloads. The scanner adapts the shared result into
its existing preparing/incomplete vocabulary and preserves cancellation separately.

Workflow catalog reads issue their own identity even when run/loading IDs are equal.
Validation and mapping run in an explicit detached task; the main actor checks the
identity after command and preparation suspension, then writes workflows and loaded
state only when changed. Preparation is cancelled on replacement, disappearance and
parent cancellation, with cooperative parser checks per record. Run-detail decoding,
commands, runtime authority, draft persistence and visible interface are unchanged.
