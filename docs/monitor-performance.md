# Profiling

Runtime profiling is unavailable until the managed Harflow runtime is integrated. The profiler refuses execution with an explicit unavailable error before copying or launching an app or writing measurement output. It must not report an empty unavailable application as a populated fixture benchmark.

`python3 scripts/profile-monitor.py --help` remains available. The future profiling interface takes an explicit version-1 `harflow.monitor-fixture` manifest generated by the engine fixture exporter, with an isolated HOME and restricted control/setup wrappers. Fixture generation remains useful for the later runtime integration work.

Build locally with `macos/build-app.sh`. The build uses an ad-hoc signature and does not install, launch, or register the app. No runtime performance measurements are claimed for this stage.
