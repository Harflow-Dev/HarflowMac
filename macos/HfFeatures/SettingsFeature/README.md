# SettingsFeature

The Settings scene (General + Harnesses tabs) for Harflow, built on the
`Coordinator → View → VM → UseCase → ViewRepository` architecture. See `AGENTS.md` for the rules
this package follows and `../../AGENTS.md` for the shared rulebook.

## Build & test

```bash
cd macos/HfFeatures/SettingsFeature
swift build
swift test
```
